# Mark Fick - Personal Website

Welcome to my personal website repository. This project is a work-in-progress, eventually connecting to Firebase for hosting and backend services.

## Tech Stack
- Next.js (React)
- Tailwind CSS v4
- TypeScript
- Firebase (Planned)

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the local development server
